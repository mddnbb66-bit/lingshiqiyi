## 洞潜致命原因（从 28 期洞潜视频归纳）
1. 无洞潜资质，用开放水域经验入洞。
2. 没铺导引绳或离开导引绳。
3. 搅起淤泥导致能见度归零。
4. 违反三分之一气体法则，单瓶无冗余。
5. 恐慌导致耗气加速；用 CCR 者出现二氧化碳中毒。
6. 拆队或独潜。
7. 空气深潜氮醉；酒后夜潜。
8. 临时起意改计划。

干洞/探洞头号杀手是大雨后进洞，其次是信任旧绳旧锚点和单一窄口。生还案例共性：找到气室、留在原地、控制呼吸，并有人坚持救援。
