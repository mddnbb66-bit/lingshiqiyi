# 《搅动泥沙》设计文档 v1

> 游戏名已定（2026-11-27）。

## 1. 一句话
一款写实的洞穴潜水恐怖模拟游戏：没有怪物，杀死你的是黑暗、淤泥、气压表和你自己的呼吸。每一关都改编自真实洞潜事故，懂行的人会在细节里认出神秘园的梗。

## 2. 设计支柱
1. **真实模拟**：气体、浮力、能见度、氮醉、二氧化碳全部按真实规律简化建模。
2. **恐怖来自物理，不来自怪物**：幽闭、零能见度、气压表指针、越来越快的呼吸声。
3. **梗是彩蛋，不是笑点**：主线不打破沉浸，梗藏在环境、成就、复盘和图鉴里。外行觉得是正经恐怖游戏，内行嘴角慢慢上扬。
4. **死了要知道为什么**：每次死亡给出“神秘园式”复盘，玩家在死亡中学会真正的洞潜规则。

## 3. 核心循环
潜前计划（选装备、配气、看洞穴图、定掉头点）→ 下潜（放线、管理气体/呼吸/浮力/踢法）→ 掉头返程（多数事故发生在返程）→ 出水或死亡 → 复盘 → 解锁图鉴与下一关。

## 4. 模拟系统
| 系统 | 规则 | 玩家感受 |
|---|---|---|
| 气体 | 耗气 = 基础呼吸率 × 环境压力(1+深度/10) × 心率倍数；压力表刻三分之一线 | 过线后表盘变红，但游戏不阻止你继续 |
| 呼吸/恐慌 | 心率由黑暗、迷路、卡住、缠绳、气量推高；心率越高耗气越快、视野越窄、手越抖 | 按住键做慢呼吸小游戏把心率压下来 |
| 淤泥与能见度 | 粒子系统；蛙踢/鞭踢扬尘少，剪刀踢和推进器扬尘多；碰底、碰壁也扬尘；沉降需要数分钟 | “我负责搅动泥沙”：一脚下去，光柱变成一面白墙 |
| 导引绳 | 进洞必须放线，可打结固定、挂箭头线标指向出口；零能见度时只能闭眼摸线；绳可能被拽断、缠人，需用刀/剪切割 | 摸到绳的那一刻是全游戏最强的安心感 |
| 浮力与配重 | BCD/干衣充放气；过重贴底扬泥，过轻顶在洞顶 | 精细操作带来的紧张 |
| 灯光 | 主灯+两支备灯，各有电量；灯光就是视野 | 换备灯时那半秒的全黑 |
| 氮醉 | 空气超过30米后出现画面扭曲、声音延迟、错误的UI提示（压力表读数“看起来还行”） | 你开始不信任自己的眼睛 |
| 二氧化碳 | CCR关卡中呼吸过快会超过滤罐能力，出现头痛、视野发黑、意识断片 | 越慌越致命 |
| 减压 | 深潜后需按停留站减压，冲上水面会得减压病 | 救援关的道德抉择：冲上去还是等 |
| 气室 | 可以呼吸续命，但氧气在下降、CO2在上升，有低温 | 活下来要靠等，而不是靠游 |
| 限制区 | 必须卸下侧挂气瓶推着过，可能卡住 | 幽闭恐惧的高潮 |

## 5. 恐怖设计
- **声音是主角**：呼吸声和调节器声是主音轨，随心率变化；气泡撞洞顶、远处岩石咔嚓、线绷紧的吱声、队友的灯光突然消失。
- **黑暗与有限视野**：只有灯锥里的东西存在。
- **不可靠的感知**：氮醉幻觉，看到并不存在的队友灯光或出口亮光。
- **静默时刻**：长段落没有任何事件，只有呼吸，压力来自玩家自己。
- **前人的痕迹**：旧绳、废弃气瓶、洞壁上前人刻的记号，偶尔有遗体（克制处理，不做猎奇特写）。
- **没有怪物，没有 jump scare 怪物**。最大的惊吓是低头看表。

## 6. HUD 与操作
- **几乎无 HUD**：深度、时间、气压需按键“低头看腕表/压力表”。心率靠呼吸声和屏幕暗角表达。没有小地图。
- 操作：WASD 游动；Shift 切换踢法；空格放线/打结；E 触线（零能见度摸线）；F 开关灯/换灯；Tab 看表；按住 R 慢呼吸；Q 卸/挂气瓶；C 切割。

## 7. 模式与关卡
### 主线：事故档案（化名改编真实事件）
1. **三米湖**（改编：克拉克斯维尔洞）教学关。湖只有3米深，头顶是石头。主题：“头顶有岩石就是洞潜”。
2. **天坑团游**（改编：卡拉维拉天坑）你是带7个游客的便宜向导。主题：清点人数、队尾押后、警示牌。
3. **追鱼的夜**（改编：湘西溶洞、追鲶鱼事件）夜里追鱼误入洞穴，迷路，找到气室，然后等五天。主题：留在原地。
4. **断线**（改编：西班牙海盗洞）引导绳断了，两人的气只够一个人出去。抉择关。
5. **深渊**（改编：鹰巢天坑）同伴临时改计划钻进窄道，推进器扬起泥沙。主题：不临时加段。
6. **打捞**（改编：布须曼洞）270米极限深度打捞多年前的遗体，CCR 呼吸、5分钟底部时间。主题：风险与收益。
7. **放弃**（改编：斯泰克方丹）你是救援潜水员，上级宣布人已死亡、要求撤队。你知道洞里有气室。结局分支。

### 自由探洞（程序生成，roguelike）
随机洞穴结构、随机岔路与淤泥区、随机队友性格。“探洞有肉鸽要素”。

### 地狱模式：临时起意
开局固定：喝了点酒、单瓶空气、没带线、夜里绕过封闭围栏。能活着出来的人很少。

## 8. 玩梗系统（嘴角上扬原则）
- **死法图鉴 = 作死打油诗**：19句诗对应死法，每触发一种死法点亮一句；集齐解锁最后一句“新人又至，再创佳绩”。
- **死亡复盘**：仿事故解说的地图复盘，红线标出你的路线、掉头点、扬尘点、过三分之一线的时间。标题格式“X人洞穴潜水，上岸后发现少了一人”。可选开启弹幕式评论（“又是临时起意”“已经进入神秘园流程了”“这里我熟，上次也是这里出事的”）。
- **成就**（示例）：
  - 我负责搅动泥沙：一次扬尘让能见度归零
  - 来都来了：过三分之一线后继续前进
  - 休想将我们拒之门外：翻过封洞围栏
  - 我就不信我会缺氧：在气室待到 CO2 中毒
  - 看了半年神秘园：零失误通关全部主线
  - 传来噩耗：第一次死亡
- **环境彩蛋**：洞口小卖部卖烤肠（“有烤肠的洞放心潜”是错的）；营地补给箱里的过期腐乳和4块压缩饼干；洞口的死神警示牌；无线电里的“小牟”。
- **队友 AI 性格**：拍照狂（停下拍照偏离引绳）、狂奔大佬（游太快把队伍甩丢）、临时起意者（中途提议“再往里看看”）、好奇宝宝（喜欢离线钻岔洞，常在队尾）。
- **加载提示**：真知识和梗交替。“头顶有岩石就是洞潜，哪怕只有3米深。”“不卖烤肠的洞不要潜。”
- **片尾字幕**：“数月之后，无人在意。”

## 9. 美术与音频
- **视角：第一人称（已定，2026-11-27）**。面镜边框遮挡视野、起雾；呼吸气泡从视野两侧上升；低头看到自己的手、腕表、压力表和手里的线轴。
- 灯光是唯一光源：体积光锥照出悬浮颗粒；扬尘时光锥变成一面白墙。
- 摸线：零能见度时画面全黑，只剩手部特写、手柄震动和触摸音效。
- 低多边形+强后处理（雾、暗角、颗粒、色差）即可出效果，不需要高精度模型。
- 调色：近黑的青绿与泥黄；只有灯光是暖色。
- 音频：双耳呼吸声、心跳、低频水压嗡鸣、远处滴水。

## 10. MVP 范围
- 平台待定：浏览器 Three.js 第一人称原型（能直接给链接试玩，画面上限较低）或 Godot/Unity（画面和性能更好，需要下载安装）。
- 内容：教学关“三米湖”+ 一个完整关“天坑团游”；气体/呼吸/淤泥/引绳/灯光五个系统；死亡复盘；图鉴解锁前5句；4个成就。

## 11. 尊重真实事件
- 全部化名改编，不用遇难者真名与真实影像。
- 梗只指向“行为”（临时起意、搅动泥沙），从不嘲笑具体的遇难者。
- 每关结尾附真实安全知识：三分之一法则、入洞必带线、至少三个光源、冗余气源、持证。
